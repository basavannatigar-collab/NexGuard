QUICK GUIDANCE

Before contacting us

i
Does NexGuard scan files for real?

Not yet. The current interface demonstrates the workflow; real detections require backend integration.

Can I upload an APK to execute it?

No. The project is designed for static analysis. APKs must never be installed or executed by the website.

Why can't I see a malware family?

A family name should appear only when a trusted engine returns a matching detection and evidence.

What about 700 MB uploads?

The limit must be enforced by the backend and hosting layer too, with timeouts and archive-expansion protections.
